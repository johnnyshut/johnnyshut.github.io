Yellow-Hammer

Организация open source инструментов для разработки на 1С: расширения для VS Code и Cursor, MCP-серверы для AI-агентов, стандарты разработки и библиотеки на OneScript.

Open Source 1С GitHub → GitHub → Telegram

1C: Platform Tools

Расширение для VS Code, упрощающее ежедневную рутину 1С-программиста. Предоставляет удобный интерфейс для работы с проектами 1С, включая разбор обработок, отчетов и конфигураций.

VS Code TypeScript 1С → Marketplace → GitHub

1C: Platform Tools MCP

MCP-сервер для AI-агентов в VS Code и Cursor. Даёт агенту доступ к командам 1C: Platform Tools: запуск тестов, профили запуска, сборка конфигурации, работа с базой.

MCP AI TypeScript → Marketplace → GitHub

dev-rules

Открытая документация по соглашениям и стандартам разработки для 1С-программистов. Гид по внутренним процессам проектной команды.

1С Стандарты Docusaurus → Сайт → GitHub

1YES

AI 1С LLM → 1yes.pro

1С Расширение GitLab GitHub → GitHub

Prometheus

Библиотека сбора метрик Prometheus для OneScript: реестр коллекторов, типы метрик (Counter, Gauge, Histogram, Summary), векторы с лейблами (Vec) и сериализация в Prometheus Text Format. Без HTTP — только накопление и сбор метрик.

OneScript Prometheus Open Source → GitHub

Prometheus Metrics

Веб-сервис с эндпоинтом GET /metrics для отдачи накопленных метрик в формате Prometheus Text Format.

OneScript Autumn Winow → GitHub

Prometheus 1C

Расширение для 1С:Предприятие 8: экспорт метрик в формате Prometheus для сбора и мониторинга (Prometheus, Grafana и др.). HTTP-сервис с GET /metrics, API совместим с библиотекой Prometheus и сервисом Prometheus Metrics.

1С Prometheus Расширение → GitHub

OneFlag

Self-hosted сервис управления фича-флагами и remote-config на OneScript — аналог Unleash и Flagsmith для закрытого контура. Дашборд, REST API, мгновенная доставка изменений через SSE, процентные выкатки, аудит в CloudEvents, SDK на базе OpenFeature.

OneScript OpenFeature SSE Docker → GitHub

winow-view

Фронт-слой для веб-сервера winow без сборщика JS: интерактивный интерфейс на htmx и Alpine.js, серверные HTML-фрагменты на JinjOS, защита от CSRF. Ни node_modules, ни шага сборки.

OneScript htmx Alpine.js → GitHub

Vanessa CI Scripts

Библиотека по динамической генерации пайплайнов для Gitlab CI. Набор скриптов Continuous Integration для 1С — аналог Jenkins Shared Library для платформы 1С:Предприятие 8.

CI/CD Jenkins OneScript → GitHub

1c-nest

Docker-образы платформы 1С:Предприятие, 1C:EDT и vanessa-runner. Рецепты открыты, образы с платформой собираются в GitHub Packages.

Docker 1С EDT → GitHub
