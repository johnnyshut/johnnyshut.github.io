prometheus

Библиотека сбора метрик Prometheus для OneScript: реестр коллекторов, типы метрик (Counter, Gauge, Histogram, Summary), векторы с лейблами (Vec) и сериализация в Prometheus Text Format. Без HTTP — только накопление и сбор метрик.

OneScript Prometheus Open Source → GitHub

prometheus-metrics

Веб-сервис с эндпоинтом GET /metrics для отдачи накопленных метрик в формате Prometheus Text Format.

OneScript Autumn Winow → GitHub

prometheus-e1c

Расширение для 1С:Предприятие 8: экспорт метрик в формате Prometheus для сбора и мониторинга (Prometheus, Grafana и др.). HTTP-сервис с GET /metrics, API совместим с библиотекой prometheus и сервисом prometheus-metrics.

1С Prometheus Расширение → GitHub

OneFlag

Self-hosted сервис управления фича-флагами и remote-config на OneScript — аналог Unleash и Flagsmith для закрытого контура. Дашборд, REST API, мгновенная доставка изменений через SSE, процентные выкатки, аудит в CloudEvents, SDK на базе OpenFeature.

OneScript OpenFeature SSE Docker → GitHub

winow-view

Фронт-слой для веб-сервера winow без сборщика JS: интерактивный интерфейс на htmx и Alpine.js, серверные HTML-фрагменты на JinjOS, защита от CSRF. Ни node_modules, ни шага сборки.

OneScript htmx Alpine.js → GitHub

CI/CD Jenkins OneScript → GitHub
